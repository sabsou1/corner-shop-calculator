#Corner Shop Calculator

A simple Python application designed to assist small business owners in tracking daily shop sales, managing operational expenses, and calculating total net profit.

📌 Project Overview

The Corner Shop Calculator is a beginner-friendly command-line program built in Python. It automates basic accounting tasks by summarizing product earnings, taking interactive inputs for store expenses, and calculating the overall net income.

✨ Features

 Sales Summary: Displays itemized earnings for various shop products (e.g., Bubblegum, Toffee, Ice Cream, Milk Chocolate, Doughnut, Pancake).

 Gross Income Calculation: Automatically calculates total gross revenue from individual item sales.

 Interactive Expense Input: Accepts user inputs for Staff Expenses and Other Expenses.

 Net Income Calculation: Computes total net profit after subtracting all operational costs from total revenue.

🛠️ Concepts & Tools Used

 Language: Python 3

 Output & Formatting: Standard ⁠print()⁠ statements and ⁠f-strings⁠ for structured text formatting.

 User Input Handling: ⁠input()⁠ function with string conversion (⁠int()⁠) to execute mathematical operations on user data.

 Basic Arithmetic: Addition and subtraction operations for financial calculations.
