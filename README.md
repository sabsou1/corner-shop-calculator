# 🛒 Corner Shop Calculator

A Python command-line application built to calculate shop earnings, operational expenses, and net profit.

## 📌 Features & Logic

* **Sales Summary:** Displays itemized earnings for various shop products (bubblegum, toffee, ice cream, milk chocolate, doughnut, and pancake).
* **Gross Income Calculation:** Automatically sums up individual product revenues to compute total gross income.
* **Expense Tracking:** Prompts users to enter staff and other operating expenses dynamically using console inputs.
* **Net Income Output:** Computes and prints the final net profit by subtracting total expenses from gross income.

## 🛠️ Concepts Applied

* **Python 3**
* **Input & Output:** `print()` with f-strings and `input()` for capturing user data.
* **Type Conversion:** Converting string inputs to integers using `int()`.
* **Arithmetic Operations:** Addition and subtraction for financial computations.
